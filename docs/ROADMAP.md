# Roadmap

Itens abaixo são recomendações da auditoria, não funcionalidades implementadas.

| Prioridade | Área | Item | Complexidade |
|---|---|---|---|
| alta | Governança | confirmar licença e diretrizes do upstream | baixa |
| alta | Segurança | substituir rate limit em memória por store compartilhado | média |
| alta | Publicação | revisar conteúdo e histórico antes de cada PR | média |
| média | Performance | estabelecer benchmark cold/warm com dataset representativo | média |
| média | Infra | definir backup, restore e rollback de migrations | média |
| média | Storage | migrar data URLs grandes para object storage | alta |
| média | Testes | adicionar E2E de autenticação, modo jogador e responsividade | alta |
| baixa | Observabilidade | centralizar métricas e logs fora do processo | média |
| baixa | Upstream | submeter branches na ordem aprovada e acompanhar conflitos | média |
